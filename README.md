## Descripción

**Rompe Bloques** es un videojuego clásico desarrollado en Python con Pygame, diseñado especialmente para personas que están dando sus primeros pasos en el mundo de la programación. Este proyecto hace parte del taller **"CREA con Python: videojuegos para principiantes"**, organizado por el laboratorio **CREA** de la Universidad de los Andes.

A lo largo del taller, aprenderás a escribir y ejecutar código Python básico, crear tus propios sprites y entender cómo la lógica de programación da vida a un videojuego real.

---

## Objetivos de Aprendizaje

- Entender qué es la programación y cómo funciona.
- Escribir y ejecutar código Python básico.
- Usar variables para almacenar información.
- Tomar decisiones en el código con condicionales.
- Repetir acciones con bucles.
- Comprender la lógica secuencial de programación.
- Introducirse a la programación orientada a objetos de forma sencilla.
- Crear un juego funcional y divertido desde cero.

## Preparación

### Requisitos:

- Tener instalado Python 3
- Instalar la librería Pygame  
  Puedes instalarla ejecutando:
  ```bash
  pip install pygame
  ```

### Para ejecutar el juego:

1. Descarga o clona este repositorio.
2. Abre una terminal o consola dentro de la carpeta del proyecto.
3. Ejecuta:
   ```bash
   python RompeBloques.py
   ```

## Guía Paso a Paso

El taller está diseñado para ser progresivo. A medida que avanzas en las secciones del código, vas aprendiendo:

### Etapas del aprendizaje:

1. **Mover la barra** usando el teclado.
2. **Detectar colisiones** entre la bola, la barra y los bloques.
3. **Asignar puntajes** y manejar vidas.
4. **Organizar tu código en clases** (bola, barra, bloque).
5. **Agregar sonidos e imágenes personalizadas**.
6. **Reiniciar el juego** al perder o ganar.
