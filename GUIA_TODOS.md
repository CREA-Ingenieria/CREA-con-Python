## 🎯 Consejos para los niños

1. **Sigue el orden:** Completa los TODOs en orden, así el juego va creciendo poco a poco.

2. **Prueba cada TODO:** Después de completar cada TODO, ejecuta el programa para ver si funciona.

3. **Lee los comentarios:** Cada TODO tiene explicaciones detalladas sobre qué hacer.

4. **Experimenta:** Una vez que completes un TODO, prueba cambiar valores:
   - Los colores (RGB)
   - La velocidad de la bola
   - El tamaño de los bloques
   - El número de vidas

5. **Busca ayuda:** Si algo no funciona, revisa el código del TODO anterior.
